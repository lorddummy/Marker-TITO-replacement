# Contributing

Commits must attribute **only you** (`g8tsz` / `197989271+g8tsz@users.noreply.github.com`) — no Cursor on the Contributors graph.

1. Disable **Cursor → Settings → Agents → Attribution**.
2. Install hooks: `./scripts/install-hooks.sh`
3. Commit with `node scripts/commit-clean.js "message"` or real Git (not Cursor auto-commit with co-author trailers).
